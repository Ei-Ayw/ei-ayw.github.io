## 这条笔记是怎么来的？

这篇是**同步测试**：文章先在本地 Obsidian 里写好，点一下同步按钮，就会自动推到博客仓库并发布到 GitHub Pages。

## 以后发布只要三步

1. 在 `source/_posts/` 里写 Markdown
2. 点 Obsidian 左侧的 GitHub 同步图标
3. 等 1～2 分钟，刷新 https://ei-ayw.github.io/ 就能看到

## 常用格式演示

写笔记常用的语法都支持：

- 列表用 `-` 开头
- **加粗**、*斜体* 随意用
- [超链接](https://github.com/Ei-Ayw) 直接写
- 代码块用三个反引号包裹

```python
def hello():
    print("Hello, Ei-Ayw!")
```

> 引用块适合放提醒：文件名用英文或拼音，`title` 用中文，这样网址好看、标题清楚。

## 小结

记住三个词就够了：**写 → 同步 → 刷新**。
